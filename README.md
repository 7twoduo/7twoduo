## Featured Projects

### [Zero-Trust Vendor Access Control Plane on AWS](https://github.com/7twoduo/Zero-Trust-Vendor-Access-Control-Plane-on-AWS)

A FedRAMP-aligned zero-trust access platform for managing vendor and partner access to protected AWS resources.

The system uses approval-based workflows, time-bound access grants, scoped IAM/STS permissions, encrypted evidence storage, and CloudTrail-backed auditability. It is designed to demonstrate how enterprises can reduce standing access, improve access governance, and generate compliance evidence for sensitive environments.

**Key capabilities:**

- Approval-based access requests
- Temporary credential issuance with AWS STS
- Least-privilege IAM role scoping
- KMS-encrypted evidence storage
- CloudTrail audit trail integration
- Terraform-based deployment

`Terraform` `Lambda` `API Gateway` `DynamoDB` `KMS` `STS` `CloudTrail` `S3`

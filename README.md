## 👋 About Me

I am a **Cloud Engineer** focused on **AWS infrastructure, Terraform, cloud security, DevOps workflows, networking, monitoring, and production-style troubleshooting**.

My work centers on solving real infrastructure problems: building secure cloud environments, automating repeatable deployments, improving access control, troubleshooting application reachability, and creating systems that are easier to operate and support.

I have hands-on experience with **EC2, VPC, IAM, S3, Lambda, RDS, DynamoDB, CloudWatch, CloudTrail, Systems Manager, CloudFront, API Gateway, WAF, ECS, ECR, Load Balancers, Security Groups, and KMS**.

I use **Terraform, Bash, Python, GitHub Actions, GitLab CI, and Jenkins** to build infrastructure that is repeatable, auditable, and easier to manage. My focus is not only deploying resources, but building cloud systems that support business outcomes: **stronger security, faster delivery, better visibility, and lower operational risk**.

I approach cloud engineering as business problem solving. The goal is not just to create infrastructure. The goal is to build cloud environments that help organizations operate securely, deploy reliably, troubleshoot faster, and reduce unnecessary risk.
